# Summarize.it

A free online tool that uses AI to summarize long pieces of text into concise, easy-to-read summaries. It helps users quickly understand the main points of an article or document.

## Features
- Paste text to summarize
- Select summary length
- Copy summarized text

## How to Use
1. Open `index.html` in your browser
2. Start using the app!

## Tech Stack
- Pure HTML/CSS/JavaScript
- No build tools required
- Use the Groq API for text summarization, and browser APIs for cutting and copying text. The app will be built using HTML, CSS, and JavaScript, with no backend required.
